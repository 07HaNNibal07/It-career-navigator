**Как безопасно вернуть службу в работу**

Перед использованием функций КОМПАС/POLYNOM, которым нужна локальная база, открыть PowerShell от администратора и выполнить:

```powershell
Start-Service -Name 'PostgreSQL'
Get-Service -Name 'PostgreSQL'
```

Дождаться состояния **Running**, затем использовать КОМПАС/POLYNOM. Альтернативно — открыть оснастку «Службы», найти именно `PostgreSQL` с указанным выше путём и нажать «Запустить». PostgreSQL 16/17 и MySQL для этого не нужны. В рамках проверки обратный запуск не выполнялся.

После последующего согласованного изменения тип запуска установлен в Manual: автоматический запуск самой службой SCM при загрузке Windows больше не настроен. Запустить её при необходимости можно указанной выше командой; другое приложение также может явно запросить её запуск. Большое выделение памяти при запуске вернётся: параметры буфера не менялись.

**Доказательства в этой папке**

- `pre-stop-check.json` — идентификация кластера и отсутствие других клиентских сессий перед остановкой.
